# ORIGEN MARRUECOS — entorno de pruebas

Repositorio de preproducción para probar cambios antes de llevarlos a `origenmarruecos.github.io`.

- No enlazar públicamente.
- La web incluye `noindex`, `nofollow` y `robots.txt` para desalentar la indexación.
- La funcionalidad en pruebas actual es el lector de códigos de barras tipo Yuka.
- Un prefijo GS1 611 se trata solo como indicio y nunca como prueba de fabricación u origen en Marruecos.

Los cambios aprobados se trasladarán después al repositorio principal.
